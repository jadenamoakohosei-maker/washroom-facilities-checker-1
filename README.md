# WASHROOM FACILITIES MANAGEMENT PROGRAM

A simple Streamlit web version of the original washroom facilities management program.

## Run locally

Install the required package:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Publish with Streamlit Community Cloud

1. Upload `app.py`, `requirements.txt`, and `README.md` to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Select your repository, the `main` branch, and `app.py`.
4. Deploy the application.
